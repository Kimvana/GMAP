Chlorophyll a (Chl a) map
-------------------------

Chlorophyll a is a central pigment in photosynthesis and features a porphyrin ring with a methyl group (-CH₃) at the C7 position, distinguishing it from Chlorophyll b. It absorbs light primarily in the blue-violet and red regions, contributing significantly to the light-harvesting process.

intended use
------------

This map is intended for treating Chlorophyll a (Chl a) molecules in protein environments (united-atom models only!). The parameters included are derived from literature, specifically from DFT calculations of the S₀ and S₁ (Qᵧ) transitions of Chl a. Parameters are provided for the electrostatic solvent shift, transition dipole coupling, and TrEsp coupling.


how to use
----------

This map has no special prerequisites aside from the presence of the relevant dynamic structure. It has been validated in a LHCII monomer system that includes both Chl a and Chl b pigments. The model follows a united atom representation, meaning only acidic protons are explicitly included, while hydrogens bound to carbon atoms are omitted.

If one wishes to change this map to work with all-atom simulations, note the following:
- at the very least, the new hydrogen atoms should be added to local atoms (meaning the funcgroupfile must be edited to include them).
- Better results would be obtained if the difference charges and TrESP charges files are also changed such that each atom has its own associated charge (instead of the hydrogens' one being added to their binding partners')


Available parameters
--------------------

Chl_a.charges_model
    no shorthand
    default: B3LYP
    options: B3LYP, HF-CIS

    Indicates which set of charges must be used. The charges are generated by different DFT models.
